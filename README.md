# Height Automation instant quote mockup

A clickable mockup of the instant-quote flow planned for Height Automation (CNC machining, Grain Valley, MO), built by TrustFlow AI.

- Buyer view: upload a STEP or STL file, see it measured in the browser, get an instant price or a quote request, and pay at a sample checkout.
- Shop view: the review page, the rate card with each material's state, and the activity log.

Everything here is sample data. There is no backend and no real payment. Sample parts are in `sample-parts/`, all in inches.
